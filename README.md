# Restaurant Address Form

A lightweight web form built exclusively with semantic HTML to capture delivery and dining locations. It focuses purely on form structure, input validation types, and data fields without any CSS styling.

### 🛠️ Key Highlights

* **Pure HTML Markup:** Written with 100% native HTML tags, relying completely on default browser rendering.
* **Input Validation:** Implements native attributes like `required` and specific type fields to capture accurate text data.
* **Semantic Structure:** Uses structured form elements like `<form>`, `<input>`, `<label>`, and `<fieldset>` for accessibility.
* **Restaurant Fields:** Tailored specifically for food logistics, featuring distinct fields for street address, city, and delivery notes.
